# Locale Jacket

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · **Русский** · [Português (Brasil)](README.pt-BR.md)

> Это перевод английского README. При расхождениях действует [английская версия](../../README.md); там же описаны технические детали и разработка.

Locale Jacket — расширение для Chrome / Edge (Manifest V3), которое показывает сайтам **разный язык браузера для разных сайтов** (например, `en-US` на google.com и `ja-JP` на apple.com), при этом язык интерфейса самого браузера не меняется.

Оно автоматизирует то, что делает **Инструменты разработчика ▸ Датчики ▸ Локаль**, и применяет это к каждой подходящей вкладке без открытия Инструментов разработчика. Правила пишутся как в Clash, sing-box или Shadowrocket: `DOMAIN`, `DOMAIN-SUFFIX`, `DOMAIN-KEYWORD`, `DOMAIN-REGEX`, `GEOSITE`, `IP-CIDR`, `IP-CIDR6`, `IP-ASN` и `GEOIP`, с исключениями `SYSTEM`/`DIRECT` и действием по умолчанию.

## Возможности

| Что видит сайт | Как подменяется | Охват |
|---|---|---|
| `Intl.*` (DateTimeFormat, NumberFormat, Collator, `toLocaleString` …) | `Emulation.setLocaleOverride` | Страница, фреймы того же и других сайтов, выделенные workers |
| `navigator.language`, `navigator.languages` | `Emulation.setUserAgentOverride` **только** с `acceptLanguage` (User-Agent и Client Hints не меняются) | Страница, фреймы, выделенные workers |
| HTTP-заголовок `Accept-Language` | Та же подмена плюс `declarativeNetRequest` для первого запроса документа | Документы, подресурсы, `fetch()`, запросы workers |
| Часовой пояс, геолокация | **По умолчанию выключены**, включаются в правиле | Страница и фреймы |

- JavaScript-API страницы не подменяются: используется только встроенная эмуляция Chrome.
- Всё работает локально: без сервера, учётной записи и телеметрии.
- Интерфейс доступен на 10 языках (см. ниже).

## Установка

**Из релиза (рекомендуется)**
1. На странице *Releases* в GitHub скачайте `locale-jacket-<версия>.zip` и распакуйте.
2. Откройте `chrome://extensions` (Edge: `edge://extensions`), включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите распакованную папку.
3. Закрепите расширение: значок (например, `EN` или `JA`) показывает профиль текущей вкладки. Для режима инкогнито включите **Разрешить использование в режиме инкогнито** на странице сведений о расширении.

**Обновление:** для распакованной папки предыдущей версии есть `locale-jacket-<старая>-to-<новая>.diff.zip`. В нём только добавленные или изменённые файлы: скопируйте их поверх старой папки, удалите файлы из `DELETED.txt` (если он есть) и перезагрузите расширение. ID расширения и настройки сохраняются.

**Файл `.crx`:** подписан тем же ключом (ID `jenefdmhnbfepiohiplfobageceacokb`), но Chrome и Edge устанавливают `.crx` не из магазина только при разрешении корпоративной политикой. Для личного использования выбирайте **Загрузить распакованное расширение**.

**Из исходного кода:** нужен Node.js 20+. Выполните `npm install` и `npm run build` и загрузите созданную папку `dist/`. Поддерживаются Chrome / Edge 125 и новее (разработано и проверено на 155).

**Правила при первом запуске:** при новой установке расширение читает `presets/default-rules.yaml` из своей папки (тот же формат, что в *Импорт / экспорт*). Отредактируйте этот файл до загрузки папки, чтобы начать со своих правил. В `.crx` этого файла нет — расширение само создаёт тот же пример набора.

## Правила по умолчанию

| Правило | Результат |
|---|---|
| `DOMAIN-SUFFIX,google.com` | `en-US` |
| `DOMAIN-SUFFIX,openai.com` | `en-US` |
| `DOMAIN-SUFFIX,apple.com` | `ja-JP` |
| `DOMAIN-SUFFIX,yahoo.co.jp` | `ja-JP` |
| `DOMAIN,accounts.google.com` | `SYSTEM` (настоящий язык) |
| по умолчанию | `SYSTEM` |

Их можно свободно изменить или удалить во всплывающем окне или на странице параметров.

## Панель отладки

Пока подменяется хотя бы одна вкладка, Chrome показывает **«Расширение Locale Jacket начало отладку этого браузера»**. Это предупреждение безопасности Chrome для API `chrome.debugger`; расширение его не скрывает. Кнопка **Отмена** приостанавливает Locale Jacket, пока вы не нажмёте **Продолжить** во всплывающем окне.

Если вы принимаете этот компромисс безопасности, [`tools/chrome-banner-flag.ps1`](../../tools/chrome-banner-flag.ps1) (Windows) добавит Chrome параметр запуска `--silent-debugger-extension-api`. Он скрывает предупреждение для **всех** расширений с разрешением на отладку. Подробнее — в [английском README](../../README.md#hiding-the-debugging-banner-optional).

## Использование

**Всплывающее окно** (значок на панели): общий переключатель; правило, профиль и статус текущей вкладки; «Проверить, что видит страница»; создание или изменение правила для текущего сайта; действие по умолчанию для остальных сайтов.

**Страница параметров:**
- **Правила:** включение / отключение, порядок, изменение, удаление; отмечаются дубликаты, конфликты и лишние правила.
- **Проверка:** введите имя хоста, чтобы увидеть подходящие правила и причину, или проверьте, что на самом деле сообщает открытая вкладка.
- **Импорт / экспорт:** JSON или YAML, с заменой или объединением.
- **Наборы данных:** скачивание, импорт и автоматическое обновление данных GeoSite / GeoIP / ASN.
- **Настройки:** язык интерфейса, режим фреймов и др.
- **Сеансы и журнал:** вкладки под отладкой и журнал событий в памяти.

## Правила

```yaml
rules:
  - type: DOMAIN-SUFFIX        # google.com и все поддомены (по границам меток)
    domain: google.com
    locale: en-US
  - type: DOMAIN               # только это имя хоста
    domain: accounts.google.com
    action: SYSTEM             # оставить настоящий язык браузера (DIRECT — синоним)
  - type: DOMAIN-KEYWORD       # имя хоста содержит текст
    keyword: microsoft
    locale: en-GB
  - DOMAIN-SUFFIX,yahoo.co.jp,ja-JP   # краткая форма в стиле Clash тоже работает
  - GEOSITE,google,en-US              # нужен набор данных GeoSite
  - IP-CIDR,17.0.0.0/8,en-US          # адрес сервера в диапазоне
  - GEOIP,LAN,SYSTEM                  # частные адреса, данные не нужны
default:
  mode: SYSTEM                 # или: mode: PROFILE + locale/languages/…
```

**Приоритет** (детерминированный; решает первое различие):
1. Тип правила: `DOMAIN` › `DOMAIN-SUFFIX` › `DOMAIN-KEYWORD` › `DOMAIN-REGEX` › `GEOSITE` › `IP-CIDR`/`IP-CIDR6` › `IP-ASN` › `GEOIP`. Правила по имени хоста всегда важнее IP-правил.
2. Внутри типа побеждает самое конкретное (суффикс с большим числом меток, IP-диапазон с более длинным префиксом).
3. Побеждает больший `priority`.
4. Побеждает правило, стоящее выше в списке.
5. Действие по умолчанию применяется, только если ничего не подошло.

Поэтому `DOMAIN,accounts.google.com → SYSTEM` всегда важнее `DOMAIN-SUFFIX,google.com → en-US`, независимо от порядка.

## Подписки на правила

*Параметры ▸ Подписки* загружает правила из файлов JSON или YAML в интернете (в формате *Импорт / экспорт*) и поддерживает их в актуальном состоянии: сразу после добавления, а затем каждый день (или неделю, месяц, никогда), с условными запросами. Ссылки на страницу файла на GitHub (`github.com/…/blob/…`) или на gist превращаются в ссылку на сам файл; адрес, который возвращает веб-страницу, отклоняется с объяснением. Правила подписок хранятся отдельно от ваших и только показываются: порядок: ваши правила, правила подписок, ваши особые правила (GEOSITE и IP-правила), особые правила подписок; среди подписок побеждает та, что выше. Из файла читается только `rules`; неверные записи пропускаются. Если правилам подписки нужен GeoSite, GeoIP или ASN, а набора данных нет, он скачивается автоматически — по адресу из раздела `datasets:` файла, иначе по адресу по умолчанию.

## Наборы данных и автоматическое обновление

Правилам `GEOSITE`, `GEOIP` по странам и `IP-ASN` нужны файлы данных. Ничего не скачивается без вашего запроса: в *Параметры ▸ Наборы данных* скачайте их по редактируемому URL или импортируйте локальный файл.

**Автоматическое обновление** (необязательно, по умолчанию выключено): проверка скачанных наборов данных при запуске браузера и/или ежедневно, еженедельно или ежемесячно. **Минимальный интервал** (по умолчанию 24 ч, от 1 до 720 ч) ограничивает каждый набор одной автоматической попыткой за период, включая неудачные, поэтому перезапуски браузера не приводят к повторным скачиваниям. Запросы условные: неизменённый файл повторно не скачивается. Наборы, импортированные из файлов, автоматически не обновляются.

IP-правила используют адрес, к которому Chrome действительно подключился; расширение не выполняет DNS-запросов.

## Язык интерфейса

Всплывающее окно и страница параметров доступны на English, 简体中文, 繁體中文, 日本語, 한국어, Deutsch, Français, Español, Русский и Português (Brasil). По умолчанию используется язык браузера; изменить его можно в *Параметры ▸ Настройки ▸ Язык интерфейса*. Это никогда не меняет то, что видят сайты.

## Обновления

Установленная версия показана рядом с заголовком всплывающего окна и внизу боковой панели параметров. *Параметры ▸ Обновления* проверяет, есть ли новая версия: только по кнопке **Проверить сейчас** или если вы включили автоматическую проверку (по умолчанию выключена, не чаще раза в 12 часов), и только по указанному адресу выпусков. Если новая версия найдена, во всплывающем окне появляется подсказка, а на странице — заметки к выпуску, ссылки для скачивания (пакет изменений, zip, crx) и шаги обновления. Chrome никогда сам не обновляет распакованную папку: скопируйте новые файлы поверх папки и нажмите **Перезагрузить расширение**. Пока репозиторий на GitHub закрытый, GitHub отвечает 404; страница это объясняет.

## Конфиденциальность и разрешения

Всё работает локально. Кроме скачивания наборов данных, которое вы запускаете сами, и автоматических обновлений, которые вы включили (всегда по указанному URL), проверок обновлений, которые вы запускаете или включаете в разделе *Обновления* (только по указанному адресу выпусков), а также подписок, добавленных в разделе *Подписки* (по их адресам, плюс наборы данных, нужные их правилам), расширение не делает сетевых запросов. Правила хранятся в `chrome.storage.local`; журнал событий существует только в памяти и содержит только имена хостов.

Разрешения: `debugger` (сама эмуляция), `webNavigation` и доступ к сайтам, `declarativeNetRequestWithHostAccess` (Accept-Language первого запроса), `webRequest` (адреса серверов для IP-правил и можно ли безопасно перезапустить загрузку страницы; только наблюдение), `alarms` (плановая проверка обновлений наборов данных и расширения, только если включена), `storage`.

## Ограничения

- Расширение не может скрыть панель отладки (см. выше).
- Страницы `chrome://` и `edge://`, страницу новой вкладки, магазины расширений и сайты, заблокированные политикой, отлаживать нельзя.
- Если ввести URL прямо в новой вкладке, первые скрипты страницы могут увидеть настоящий язык; HTTP-заголовок при этом правильный, а страница может один раз автоматически перезагрузиться.
- В одном процессе отрисовки может быть только одна локаль Intl; разные профили в общем процессе отображаются как «Частично».
- Service workers и shared workers не подменяются.
